# 生物信息学与数据分析实践 (Bioinformatics Data Analysis Practice)

## 📖 项目简介
本项目为个人在生物信息学与数据科学方向的学习与实践记录，主要包含利用 Python (Pandas, SciPy, Matplotlib 等) 进行数据清洗、统计检验以及 GEO 数据库 (Gene Expression Omnibus) 基因表达数据的预处理与分析。旨在掌握生信分析的基础流程与核心代码能力。

## 🛠️ 技能栈 (Skills)
*   **编程语言:** Python
*   **数据分析:** Pandas, NumPy
*   **统计与生信:** SciPy (卡方检验等), GEO 数据预处理 (Log2转换, 基因均值计算与排序)
*   **数据可视化:** Matplotlib, Seaborn

## 📂 内容目录 (Content)
本项目按照学习进度分为以下几个模块（详细代码见对应 `.ipynb` 文件）：

*   **Day 1: 统计基础与可视化** - 卡方检验的实现与血型分组分布图的绘制。
*   **Day 2: Pandas 基础** - 数据读取、写入及基础数据清洗操作练习。
*   **Day 3: 医学数据分析** - 血脂数据分析实战。
*   **Day 4: 生信数据预处理** - GEO 数据库表达矩阵的 Log2 转换与标准化处理。
*   **Day 5: Pandas 进阶** - 常用语法与数据字典操作。
*   **Day 7: 基因表达分析** - 基因均值的计算与表达量排序。

## 🚀 运行环境
请确保安装了以下依赖包：
`pip install pandas numpy scipy matplotlib seaborn jupyter`
