# Bioinformatics & Data Analysis Practice

本仓库记录了个人在生物信息学与数据科学方向的基础实操代码。内容主要涵盖 Python 数据处理、统计学检验及 GEO 表达谱数据的预处理。

## 🛠️ 技能实践 (Practiced Skills)

*   **Data Wrangling (Pandas)**: 实现表格数据的读取、清洗、切片及分组统计；使用 Pandas 处理基础临床/实验数据。
*   **Statistics & Visualization**: 使用 `SciPy` 进行卡方检验 (Chi-square test)，并结合 `Matplotlib` / `Seaborn` 绘制数据分布图。
*   **Bioinformatics Preprocessing**: 针对 GEO 数据库表达矩阵进行 Log2 转换与标准化处理；完成基因均值的计算与表达量排序。

## 📂 仓库结构 (Contents)

*   包含日常基础语法练习、数据字典整理以及核心的数据分析流程代码（详见 `.ipynb` 文件）。

## ⚙️ 运行环境 (Environment)

*   **Language**: Python 3
*   **Libraries**: `pandas`, `numpy`, `scipy`, `matplotlib`, `seaborn`
*   **Environment**: Jupyter Notebook
